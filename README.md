# Solid Glass

Apple calls their new design language Liquid Glass, but when you shrink them down to PNGs, it kind of becomes Solid. Get it?


Solid Glass is a theme ecosystem that brings Liquid Glass aesthetics to older jailbreakable devices, built around Human Interface Guidelines.
Featuring the all new **Solid Glass 18** for those who prefer the flat design.

# Features
- 4 beautiful variants: Light, Dark, Clear Light & Clear Dark;
- iOS 27 Status Bar icons;
- Updated icons for Settings pages;
- Built-in icon mask for a unified look across every app.

# Clear Icon Architecture
Every Clear variant is handcrafted using a multi-layer stack to deliver realistic glass effect and specular reflections while revealing your wallpaper.

<img width="834" height="501" alt="Screenshot 2026-07-26 at 5 54 35 PM" src="https://github.com/user-attachments/assets/c50ddd73-9b7f-4dea-b345-2e3502fd14fe" />

Clear icons are built with 3 distinct layers:
* The main Background;
* Specular for light reflections;
* The actual object itself defining each icon.

# Requirements
* **Settings icons** requires *SnowBoard Settings Icons Extension*;
* **Status Bar** requires *SnowBoard StatusBar Extension*;
* **Icon Masks** requires *SnowBoard Icon Masks Extension*.

*These extensions are natively included in **Anemone**, you'll only need these if you're using **SnowBoard**.*
